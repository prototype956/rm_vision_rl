## 仍需由具体实验回答的问题

合成测量用近似噪声、延迟和几何遮挡，不能直接外推完整图像检测链路或实机命中性能。全路径可见性准入证明场景具有可观测条件，也不保证控制器实际不失锁或命中。

NUC 已有 Actor 推理和仿真闭环接口，串口与固件接入仍待实现。CPU 推理 P99 ≤ 10 ms 是目标，是否达标须检查对应模型、硬件和测量结果；该延迟不包含视觉与物理仿真。

Reset 重建世界与资产、并行同步和序列优化都会影响吞吐。[2026-09-24 的 CPU 测量](training_performance.md)属于旧 MLP，不能据此推断当前 GRU/128 环境的吞吐、收敛或泛化。ARM64 平台及独立分发所需的 Rust/C++/Python 依赖也须在目标环境验证。

## 证据与复现

检查一次运行时，先核对源码、配置、二进制和资产身份，再区分预算完成、战斗门槛、热锁门槛和结算完整性。保留预热、环境和结算失败，不能通过更换冻结场景抬高成绩。多随机种子、等预算比较和实机结果不足时，目前无法判断策略的普遍优势。

新增行为应检查观测/动作契约、状态复位、时间截断自举及旧检查点兼容性。测试入口为 `python -m unittest discover -s tests -v`；测试存在与通过须分别表述。
