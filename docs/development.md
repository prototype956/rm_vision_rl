# 当前状态与开发顺序

更新：2026-09-23。本文记录当前功能和下一步交付，不保存历史批次清单。

## 已有能力

- 无渲染物理进程、显式步进、重置、暂停查询和多实例通信。
- 出生随机化，静止、正弦平移和匀速旋转目标。
- 请求、供弹、出膛、伤害和弹丸终结事件，以及关窗后自然结算。
- 合成二维测量接入真实 PnP、预测器、弹道和 TinyMPC。
- 禁射预热、规则评估、九动作/只开火回调、观测历史和独立计分。
- 随机旋转靶 `RMRotationFire-v0` 和静止靶 Gymnasium 环境 `RMStaticFire-v0`：规则两动作/联合九动作、固定数组观测、逐步伤害奖励、终止/截断和进程清理。
- 同周期观测/动作拆分、无回调周期采样、目标代次历史复位、取消未提交周期。
- MaskablePPO/MLP 单环境训练入口、默认随机原地旋转场景（保留固定正面靶）、原始奖励日志、原子检查点和优化器恢复。

这些能力支撑 Gym 采样、PPO 训练和脚本策略实验，当前没有 GRU 训练、模型导出或部署模块。历史验收与诊断工具已删除，过去不同版本的报告不作为当前代码的验收结论。

## 当前交付与后续顺序

当前已封装静止/旋转靶标准环境：

1. **标准接口。** `reset/step` 使用同周期观测和动作；支持 `fire_only` 的 `Discrete(2)` 和 `joint` 的 `Discrete(9)`，省略模式保持旧行为。
2. **奖励和回合边界。** 使用逐步实际伤害；死亡为终止，默认 30 秒为时间截断，返回真实末观测供训练器自举。训练不叠加评估尾部结算。
3. **所有控制状态的采样。** 无回调也推进历史和物理，目标重建清空旧历史；故障停止采样并清理进程。
4. **单环境 PPO。** 当前用 DummyVecEnv 接入自动 Reset、动作掩码和时间截断自举，支持更新、保存和恢复。后续按实际吞吐决定是否增加多进程采样或优化 Reset/通信。
5. **后续学习。** 短训练只检查学习链路；已提供 18 场景成对效果对照；长时间训练和 GRU 仍需单独开展。

实现检查结合契约测试与真实闭环；新增模式需检查旧检查点兼容性、时钟连续性和实际控制结果。
最终由用户手工验收，需要时再按用户要求提供针对性数据；不自行长期录制；成对评估矩阵使用本次约定的 18 个场景。

## 当前问题

| 问题 | 影响 |
| --- | --- |
| Reset 重建物理世界和资产实例 | 采样吞吐仍需测量 |
| 合成测量使用近似噪声、延迟和遮挡 | 不能直接外推完整视觉链路性能 |
| 随机出生可能预热超时 | 需保留并分类处理，不能静默过滤失败样本 |
| 默认 MPC 与 200 次候选配置不同 | 每次明确选择并记录，候选文件不会自动加载 |
| 己方固定、目标仅支持分开的平移/旋转 | 首版明确限制，组合运动和己方移动后续扩展 |

## 后续阶段

基础环境完成后，再扩展场景、对比渲染观测并标定误差，扩展已接入的只开火与联合选板策略对照。训练器与采样环境优先位于同一台服务器，NUC 承担本地联调和评估。

DGX Spark 是 ARM64，需要单独验证 Rust、C++ 和 Python 依赖。当前工具查询本机 rustc 的动态库目录，尚无独立分发包。模型导出、NUC C++ 推理和实机通信随后实现，不作为基础训练接口完成的前置条件。

GRU 需要序列 rollout、隐藏状态与复位及动作掩码的配套支持，不能直接替换 MLP 层。
模型构建和加载集中在训练层，检查点记录算法、策略类型和观测契约；不把循环记忆放入仿真通信。
