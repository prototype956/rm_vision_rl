## 正式 Talos 图像闭环

通过正式项目 `scripts/run_simulation_vision.sh` 启动正式构建的主程序，最多运行 240 秒；
仿真绑定 E 核、视觉绑定 P 核。输入来自实际渲染图像，经过检测、PnP、预测、规则火控、
MPC 和物理执行器。仅用方向键、R 与 F5 操作，无 Space/G 手动射击。

本次是默认场景集成验收，场景同时存在步兵与现有英雄资产，自动跟踪可能选择任一目标；
它不是阶段三标准场景集，也不作为英雄小装甲适配或训练验收。非英雄四装甲的规则等价
由上述固定输入差分覆盖。

- 日志确认外部控制开启、TRACKING、有效命令与自动射击；裁判禁发时仍有有效跟踪命令。
- R 重置关闭外部控制，重新启用后能恢复跟踪及射击；目标战亡后进入丢失并停止目标命令。
- 回合 2 稳定快照：实际出膛 38 发、实际伤害 700、击毁 2 个目标。
- 回合 3 在有界运行结束时：本地接纳 20 次单发请求，实际出膛 12 发、拒绝 8 次、伤害 240。
  本地接纳不是出膛确认；这正是阶段二可靠事件账本需进一步解决的接口边界。
- 正常由有界脚本发送停止信号；日志记录相机关闭。外层启动脚本报告 130，属于此次主动停止，
  不是视觉算法异常退出。两个子进程已停止，原录制配置逐字节恢复，没有启用 MCAP。

### 耗时口径

最后一段采样原请求 20 秒，但在有界运行停止时结束，实际获得 1,070 个控制样本。
其中 **468 个样本同时满足外部使能、TRACKING、有效命令发布**，单独统计如下：

| 指标 | 有效跟踪样本 |
| --- | ---: |
| 同步控制计算 P50 | 96.24 μs |
| P95 | 152.52 μs |
| P99 | 202.11 μs |
| 最大值 | 294.41 μs |
| 计算超过 10 ms | 0 / 468 |
| 周期超过 11 ms | 0 / 468 |
| 唤醒迟到超过 1 ms | 1 / 468 |

全部 1,070 个样本计算最大值为 408.803 μs，没有计算超过 10 ms 的周期。
这是一次短时规则控制集成测量，不能证明最坏时延、长期稳定性或未来 RL 推理耗时。
此前 3,501 个全 LOST 样本、30 秒采样中大量 LOST 样本不用于宣称跟踪性能。
计时包含同步核心、快照复制及发布结果处理，排除 Send；与线程周期/调度迟到分开。
静态检查和构建已在这段最终采样前结束。

证据：[分组统计](../artifacts/phase1/production-round3-latency.json)、
[原始有界 JSON](../artifacts/phase1/production-round3.jsonl)。
